# ITSchool — сайт репетитора по информатике

Сайт Ямкиной Елены Владимировны: визитка, каталог учебных материалов
и панель управления для загрузки видеоуроков и файлов.

Живая версия: https://yamkin-anton.github.io/rep/

---

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная страница: услуги, цены, отзывы, форма записи |
| `lectures.html` | Каталог материалов с поиском и фильтром по тегам |
| `lecture.html` | Страница одного урока: плеер, описание, файлы |
| `login.html` | Вход и регистрация ученика |
| `admin.html` | Панель управления (только для администратора) |
| `assets/css/main.css` | Вся вёрстка и фирменный стиль |
| `assets/js/config.js` | **Единственный файл, который нужно заполнить** |
| `db/schema.sql` | Скрипт создания базы данных |

Сборка не нужна: это обычные HTML, CSS и JS. Правите файл — делаете `git push` —
GitHub Pages обновляет сайт сам.

## Настройка

**Уже сделано.** База данных развёрнута и подключена, отдельно настраивать
ничего не нужно. Что именно готово:

| Что | Значение |
| --- | --- |
| Проект Supabase | `itschool-rep`, регион Frankfurt (`eu-central-1`) |
| Организация | ITSchool |
| Ключи в `config.js` | прописаны, тип `publishable` |
| Таблицы | `profiles`, `lectures` + витрина `lectures_catalog` |
| Хранилища | `covers` (публичное, до 5 МБ), `materials` (закрытое, до 50 МБ) |
| Подтверждение почты | отключено — ученик входит сразу после регистрации |
| Site URL | `https://yamkin-anton.github.io/rep/` |

Пароль базы данных лежит в файле `C:\Users\user\rep-supabase-db-password.txt`
на вашем компьютере. В репозиторий он не попадает и в обычной работе не нужен —
пригодится только для прямого подключения к Postgres.

### Единственный оставшийся шаг — стать администратором

1. Откройте на сайте страницу **Войти** и зарегистрируйтесь на вкладке
   **Регистрация** своей рабочей почтой.
2. Зайдите в [панель Supabase](https://supabase.com/dashboard) → проект
   `itschool-rep` → **SQL Editor** → **New query** и выполните,
   подставив ту же почту:

   ```sql
   update public.profiles
   set role = 'admin', approved = true
   where email = 'ваша-почта@example.com';
   ```

3. Обновите страницу сайта — в шапке появится кнопка **Админка**.

Сделать это за вас нельзя: пароль от учётной записи придумываете вы,
и знать его я не должен.

### Если понадобится развернуть заново

Скрипт `db/schema.sql` можно выполнить в **SQL Editor** повторно —
он не ломает существующие данные и восстанавливает все права доступа.

## Как пользоваться

### Добавить урок

**Админка → Добавить урок.** Обязательное поле одно — название. Дальше:

- **Ссылка на видео** — вставьте адрес ролика. Сайт сам определит площадку
  и вставит нужный плеер. Работают YouTube, VK Видео, Rutube, Дзен
  и прямые ссылки на файл `.mp4`.
- **Обложка** — картинка 16:9 до 5 МБ. Если не загрузить, покажется фирменная заставка.
- **Архив** — `.zip` с материалами к занятию, до 50 МБ на бесплатном тарифе.
- **Теги** — через запятую (`ЕГЭ, Python`). Из них сами собираются фильтры в каталоге.
- **Открытый урок** — галочка делает урок видимым всем без входа на сайт.
- **Опубликовать** — снимите галочку, чтобы сохранить черновик и доработать позже.

### Открыть доступ ученику

Ученик регистрируется сам на `login.html`. После этого он появляется
на вкладке **Ученики** — нажмите **Открыть доступ**, и закрытые уроки
станут ему видны. Кнопка **Закрыть доступ** отзывает его обратно.

### Где хранить видео

Видео на сайт не загружается — только ссылка. Это сделано намеренно:
хранение видео в Supabase быстро упрётся в 1 ГБ бесплатного тарифа.

Практический совет: заливайте на **VK Видео** — в России оно открывается
у всех и без VPN, в отличие от YouTube. В настройках ролика можно поставить
доступ «по ссылке», чтобы он не появлялся в поиске.

## Как устроен доступ

Три уровня, и все они проверяются на стороне базы данных, а не в браузере —
через консоль разработчика их не обойти:

| Кто | Что видит |
| --- | --- |
| Гость | Главную, каталог целиком (обложки, названия, описания) и открытые уроки |
| Ученик без доступа | То же самое: закрытые уроки видны в каталоге, но под замком |
| Ученик с доступом | Все опубликованные уроки: видео и файлы |
| Администратор | Всё, включая черновики, плюс панель управления |

Технически: витрину каталога отдаёт представление `lectures_catalog`
с безопасными полями. Ссылка на видео и путь к архиву лежат в таблице
`lectures`, закрытой политиками RLS. Файлы из хранилища `materials`
выдаются по временным ссылкам, которые живут один час.

## Возможные вопросы

**Каталог пустой.**
Так и должно быть, пока не добавлен ни один урок. Жёлтая плашка «раздел
не подключён» появляется только если из `config.js` пропали ключи.

**«Панель доступна только администратору».**
Не выполнен запрос `update public.profiles ... set role = 'admin'` —
см. раздел «Настройка».

**Файл не загружается, ошибка про размер.**
Бесплатный тариф Supabase ограничивает файл 50 МБ. Разделите архив
или подключите платный тариф.

**Видео не проигрывается.**
Проверьте настройки приватности ролика на площадке: у YouTube нужен доступ
«Доступ по ссылке» (не «Ограниченный»), у VK — разрешённое встраивание.
